## Selected work

### 01 · SocialDog

A private operational software system for a campus café, designed around the handoffs between customers, store staff, managers, inventory, and back-office workflows.

_Public implementation repository: private._

### 02 · [13110](https://github.com/banshanbans/13110)

A policy experimentation system for comparing how the same simulated world evolves under control and treatment policies.

Implemented same-checkpoint A/B branching, human approval gates, constrained agent actions, deterministic quarterly settlement, and replayable evidence across central, provincial, and automaker subjects.

`Multi-Agent · Simulation · FastAPI · React · Auditability`

### 03 · [AnjuGuard · 长者友好家](https://github.com/banshanbans/AnjuGuard)

A home-safety assessment product that helps families move from visible risk evidence to prioritized remediation choices and reference budgets.

Extended the RASSAR foundation into an elder-friendly product workflow with photo quality gates, structured risk evidence, deterministic scoring, A/B/C remediation plans, and web/iOS capture paths.

`Multimodal AI · Accessibility · FastAPI · React · iOS`

### 04 · [SoloShot AI](https://github.com/banshanbans/Hackathon)

A prototype for turning a reference shot into an executable, cross-device photography workflow rather than stopping at image description.

Built the reference-to-ShotPlan-to-capture workflow across FastAPI, React H5, browser pose estimation, and a native iOS client with short-lived task handoff and result feedback.

`AI Agent · Computer Vision · FastAPI · React · iOS`
